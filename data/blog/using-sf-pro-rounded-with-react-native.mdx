Apple's San Francisco is the default system font used by React Native on iOS. Apple also provides a rounded version of the font called SF Pro Rounded which is used in apps such as Reminders. The font variant can be used in Swift apps by setting the [Font.Design](https://developer.apple.com/documentation/swiftui/font/design) to `rounded`, however I couldn't find any information on how to do it in React Native and all LLMs were lying hence creating this post.

## How to use SF Pro Rounded with React Native

React Native supports the `ui-rounded` font family out of the box, so you can use it in your app by setting the `fontFamily` prop to `ui-rounded`. Learn more about `ui-rounded` [here](https://drafts.csswg.org/css-fonts-4/#ui-rounded-def).

```tsx
import { Text, StyleSheet } from "react-native";

const styles = StyleSheet.create({
  text: {
    fontFamily: "ui-rounded",
  },
});
```

## SF Pro Rounded with NativeWind

Extend your NativeWind theme to include the `ui-rounded` font family.

```ts
import { extendTheme } from "nativewind";

module.exports = {
  content: ["./src/**/*.{js,ts,jsx,tsx}"],
  presets: [require("nativewind/preset")],
  theme: {
    extend: {
      fontFamily: {
        rounded: ["ui-rounded", "system-ui", "sans-serif"],
      },
    },
  },
};
```

Then use it in your app:

```tsx
import { View, Text, StyleSheet } from "react-native";

function App() {
  return (
    <View>
      <Text className="font-rounded">Hello, world!</Text>
    </View>
  );
}
```

## Setting a global font family in React Native

In react native styles don't cascade like in regular css, so one way to set the global font family is to create a custom `<Text />` component that sets the font family that can be used throughout the app.

```tsx
import { Text as RNText, StyleSheet } from "react-native";
import cn from "clsx";

function Text({ children, className, ...props }: TextProps) {
  return (
    <RNText className={cn("font-rounded", className)} {...props}>
      {children}
    </RNText>
  );
}
```

## Other variants: SF Mono

React Native also supports the `ui-monospace` font family [out of the box](https://reactnative.dev/docs/text-style-props#fontfamily), so you can use it in your iOS app by setting the `fontFamily` prop to `ui-monospace`.
